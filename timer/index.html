Getting started

Use the Classroom Timer for a quick activity countdown or as a stopwatch.

1

Choose a time

Pick a quick preset or enter hours, minutes, and seconds.

2

Start, pause, or add time

The countdown remains accurate when the browser tab is in the background. Add one minute at any time.

3

Save frequent countdowns

Create named presets in Settings. They are stored only in this browser and may be lost if site data is cleared.
