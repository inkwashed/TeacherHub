Before going offline

  1. Open this page online in the browser or app you will use.
  2. Wait for Offline files to say Ready. Choose Prepare for offline use if needed.
  3. Before class, disconnect and check that your tools open.

Keep tools up to date

Use Check for updates while online. If Apply update appears, save your work first, then apply it. Reload other open app pages afterward. Clicking an app title refreshes its page; it does not apply a pending update.

Add Teacher Tools as a web app (optional)

After adding Teacher Tools as a web app, open it and confirm its Offline files say Ready. Files and saved data may be separate from your browser.

For this device

Chrome or Edge

Use Chrome or Edge on a computer.

  1. Open Teacher Tools in Chrome or Edge.
  2. Choose Install Teacher Tools above, or use the browser’s app-install option.
  3. Open the Teacher Tools web app.
For this device

Safari on Mac

Use Safari’s Add to Dock option, if available.

  1. Choose File or Share → Add to Dock.
  2. Confirm the name and choose Add.
  3. Open Teacher Tools from the Dock.
For this device

iPhone or iPad

These steps use Safari; browser menus may differ.

  1. Open Teacher Tools in Safari and tap Share.
  2. Choose Add to Home Screen.
  3. If shown, enable Open as Web App, then tap Add.
For this device

Android phone or tablet

These steps use Chrome.

  1. Open Teacher Tools in Chrome.
  2. In the browser menu, choose Add to Home screen or Install app.
  3. Confirm, then open the Teacher Tools web app.

Back up or move your data

Your schools, notes and settings stay in the browser or app where you saved them. Offline tool files are not a backup of that data.

Use Profile → Export & Import Backup to save or restore a JSON backup.

  1. Export a backup from the browser or app containing your data.
  2. In the new browser or app, open Profile → Export & Import Backup and restore the file.
  3. Check your data before removing the old browser or app.

Google Calendar, new Selfie imports and external links need internet. Browsers may remove stored files or data, so keep separate backups.
