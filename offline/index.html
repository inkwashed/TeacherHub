Step 1: Install Teacher Tools as a web app (optional)

Check the recommended steps below for instructions on installing Teacher Tools as a web app on your phone or computer.

For this device

Chrome or Edge

Use Chrome or Edge on a computer.

  1. Open Teacher Tools in Chrome or Edge.
  2. Choose Install Teacher Tools above, or use the browser’s app-install option.
  3. Open the Teacher Tools web app.

Safari on Mac

Use Safari’s Add to Dock option, if available.

  1. Choose File or Share → Add to Dock.
  2. Confirm the name and choose Add.
  3. Open Teacher Tools from the Dock.

iPhone or iPad

These steps use Safari; browser menus may differ.

  1. Open Teacher Tools in Safari and tap Share.
  2. Choose Add to Home Screen.
  3. If shown, enable Open as Web App, then tap Add.

Android phone or tablet

These steps use Chrome.

  1. Open Teacher Tools in Chrome.
  2. In the browser menu, choose Add to Home screen or Install app.
  3. Confirm, then open the Teacher Tools web app.

Step 2: Download the Teacher Tools Offline file pack
  1. Open this page online in the browser you want to use.
  2. Click Download Offline Files. Wait for Offline Files to show Downloaded.
  3. Disconnect from the internet and test Teacher Tools in the same browser to make sure everything is working.
3

Step 3: Keep Teacher Tools up to date
  1. Make sure you are connected to the internet, then click Check for Updates to download any available updates to the Offline files.
  2. If Apply Update appears, save or sync your data first, then click to apply the update.
  3. Reload any open app pages to make sure the updates are applied and visible.
4

Step 4: Export & Import your data

Your schools, notes and settings are only saved locally in your browser unless you set up File Sync (Autosave) or download a backup file of your data.

Download a backup file

  1. Open Teacher Tools in the browser you currently use.
  2. Open Profile → Export & Import.
  3. Make sure all boxes are checked, then click Export All Data to download your backup file.

Import a backup file

  1. Open Teacher Tools in your new browser or app.
  2. Open Profile → Export & Import.
  3. Click Import Backup and choose your backup file to copy the data into that browser.
