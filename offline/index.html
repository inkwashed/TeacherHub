Recommended for this device

Installation options

Choose the browser you plan to keep using. Installing from the same browser is usually the easiest way to retain its Teacher Tools data.

Best match

Chrome or Edge

Recommended on Windows and Mac. Desktop Chrome and Edge also support the beta linked data file for automatic local saving and cross-browser pulls.

  1. Open this page in Chrome or Edge.
  2. Choose Install Teacher Tools above or use the browser’s Install app command.
  3. Open Teacher Tools from the new app icon.
Best match

Safari on Mac

Available on macOS Sonoma 14 or later. Safari does not support linked data files, so use Backup & restore when moving data.

  1. In Safari, choose File → Add to Dock.
  2. Open the new Teacher Tools web app.
  3. Restore your backup there if your existing data does not appear.
Best match

iPhone or iPad

Use your browser’s Add to Home Screen option. The installed version runs as an iOS web app, regardless of which browser added it.

  1. Open this page in your preferred browser and tap Share or its menu button.
  2. Choose Add to Home Screen.
  3. If shown, turn on Open as Web App, then tap Add.
Best match

Android phone or tablet

Chrome provides the most direct installation and offline experience.

  1. Open this page in Chrome.
  2. Choose Install app or Add to Home screen.
  3. Launch Teacher Tools from its app icon.

Protect and move your saved data

Application files and teacher data are stored separately. Updating the app should not remove your data, but switching browsers or profiles can create a separate storage area.

Checking this browser…

  1. Download a complete backup in the browser where your current data lives.
  2. Install or open Teacher Tools using the new browser or app.
  3. Restore the backup inside that installation.
  4. Confirm your schools and applet data before clearing the original browser.

The first offline setup requires an internet connection. Google Calendar and external links still require internet. Browsers may remove local site data under storage pressure, so keep periodic backups.
