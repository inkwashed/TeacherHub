Spinner Wheel help

Choose a saved class number set or one of your reusable custom lists, then spin.

1

Choose the wheel mode

Use Numbers to choose a school and class from Scheduler. New class ranges use the saved student count when available, and you can still adjust the minimum, maximum, or exclusions. Use Custom Choices to keep a reusable bank of named lists.

2

Decide what happens after a spin

Selections can stay available for repeats or be removed temporarily for the current round. Removed choices return when you restore the round, change wheel entries, or reload the page.

3

Spin and announce the result

The selected choice is shown in full and announced for screen readers. Presentation mode enlarges the wheel for smartboards and landscape displays, while reduced-motion preferences replace the long spin with a brief transition.

Your settings and custom choices are saved only in this browser. Clearing site data can remove them; export a backup if the list is important.
